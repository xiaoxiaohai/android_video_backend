# Legal Web Pages (Static)

This folder contains a small static website with two legal pages:

- `privacy.html` (Privacy Policy)
- `terms.html` (Terms of Service)

## Open locally

Option A (double-click):

- Open `privacy.html` or `terms.html` directly in a browser.

Option B (recommended, avoids some browser cross-file quirks):

```bash
cd /Users/xiaohai/Desktop/Developer/android_video/docs/legal-web
python3 -m http.server 5173
```

Then visit:

- http://localhost:5173/privacy.html
- http://localhost:5173/terms.html

## Customize

Search for `[TO FILL]` and replace placeholders (jurisdiction, subscription terms, age limits, etc.).
