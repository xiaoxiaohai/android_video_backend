## 🚀 优化方案

### 优化 1: 缓存 GitHub 密钥 ⭐⭐⭐
**节省**: ~500ms
**难度**: ⭐ 简单
**效果**: 立竿见影

```javascript
// 当前: 每次都获取
const keys = await getMasterKeys();  // 500ms

// 优化: 内存缓存
let keysCache = { data: null, expiry: 0 };

async function getMasterKeys() {
  if (keysCache.data && Date.now() < keysCache.expiry) {
    return keysCache.data;  // 0ms 🚀
  }
  const keys = await fetchKeys();
  keysCache = { data: keys, expiry: Date.now() + 3600000 }; // 1小时
  return keys;
}
```

**理由**: GitHub 密钥很少变化（几天甚至几周才更新一次）

---

### 优化 2: 并行请求 ⭐⭐⭐
**节省**: ~300-500ms
**难度**: ⭐⭐ 中等
**效果**: 显著

#### 场景 A: embed 页面 + GitHub 密钥并行

```javascript
// 当前: 串行
const embedRes = await fetchText(embedUrl);      // 300ms
const keys = await getMasterKeys();              // 500ms
// 总计: 800ms

// 优化: 并行
const [embedRes, keys] = await Promise.all([
  fetchText(embedUrl),                           // 300ms ┐
  getMasterKeys()                                // 500ms ┘ 并行
]);
// 总计: 500ms (节省 300ms)
```

#### 场景 B: 多个独立请求并行

```javascript
// 当前: 串行
const watchRes = await fetchText(watchUrl);      // 300ms
const episodeRes = await fetchText(episodeUrl);  // 200ms
const embedRes = await fetchText(embedUrl);      // 300ms
// 总计: 800ms

// 优化: 能并行的都并行
// (这个不太适用，因为后面的请求依赖前面的结果)
```

### 优化 3: 连接池复用 (Keep-Alive) ⭐⭐
**节省**: ~100-200ms
**难度**: ⭐ 简单
**效果**: 累积明显

```javascript
import http from 'http';
import https from 'https';
import axios from 'axios';

// 创建全局 axios 实例，启用连接复用
const httpClient = axios.create({
  httpAgent: new http.Agent({
    keepAlive: true,
    maxSockets: 50,
    maxFreeSockets: 10,
    timeout: 60000
  }),
  httpsAgent: new https.Agent({
    keepAlive: true,
    maxSockets: 50,
    maxFreeSockets: 10,
    timeout: 60000
  }),
  timeout: 15000
});

// 使用
const response = await httpClient.get(url);
```

**理由**: 避免每次请求都重新建立 TCP/TLS 连接

### 优化 5: 本地备份密钥 ⭐⭐⭐
**节省**: GitHub 不可用时 ~500ms
**难度**: ⭐⭐ 中等
**效果**: 提高可靠性

```javascript
// 本地备份密钥文件
const BACKUP_KEYS_PATH = './data/megacloud-keys.json';

async function getMasterKeys() {
  // 1. 尝试内存缓存
  if (keysCache.data && Date.now() < keysCache.expiry) {
    return keysCache.data;
  }

  // 2. 尝试从 GitHub 获取
  try {
    const keys = await fetchFromGitHub();
    keysCache = { data: keys, expiry: Date.now() + 3600000 };

    // 保存到本地备份
    await fs.writeFile(BACKUP_KEYS_PATH, JSON.stringify(keys));
    return keys;
  } catch (error) {
    console.warn('GitHub fetch failed, using backup');
  }

  // 3. 从本地备份读取
  try {
    const backup = await fs.readFile(BACKUP_KEYS_PATH, 'utf8');
    return JSON.parse(backup);
  } catch {
    throw new Error('No keys available');
  }
}
```

### 优化 6: 智能缓存完整结果 ⭐⭐
**节省**: 重复请求 ~3000ms (100%)
**难度**: ⭐⭐⭐ 复杂
**效果**: 极佳（但需谨慎）

```javascript
// 使用 LRU 缓存
import LRU from 'lru-cache';

const resultCache = new LRU({
  max: 500,              // 最多 500 个条目
  ttl: 1000 * 60 * 10,  // 10 分钟过期
  updateAgeOnGet: true   // 访问时刷新
});

async function resolveM3u8Demo({ watchUrl, ...options }) {
  const cacheKey = `${watchUrl}`;

  // 检查缓存
  const cached = resultCache.get(cacheKey);
  if (cached) {
    return { ...cached, cached: true }; // 0ms 🚀🚀🚀
  }

  // 正常解析
  const result = await actualResolve({ watchUrl, ...options });

  // 存入缓存
  resultCache.set(cacheKey, result);
  return result;
}
```

**注意**:
- ⚠️ 视频链接可能会过期（通常几小时）
- ⚠️ 不同用户可能需要不同的 cookie/token
- ✅ 适合公开内容 + 短期缓存
