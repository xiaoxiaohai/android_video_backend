# 内容分页接口（电影/电视剧共用）

本文档基于当前后端实现：
- `/Users/xiaohai/Desktop/Developer/android_video/backend/src/routes/content.js`
- `GET /api/content`

## 1. 接口说明

- 方法：`GET`
- 路径：`/api/content`
- 线上地址：`https://api.nexamedia.app/api/content`
- 用途：电影和电视剧共用同一个分页接口

## 2. 查询参数

- `type`（可选）
  - `1`：movie
  - `2`：tv
  - 不传：返回 movie + tv 混合
- `page`（可选）
  - 默认 `1`
  - 必须 `>= 1`
- `size`（可选）
  - 默认 `30`
  - 范围 `1..500`
- `q`（可选）
  - 标题关键字，按 `title ILIKE '%q%'` 搜索
- `genre`（可选）
  - 题材筛选，支持逗号分隔多值（OR 关系）
  - 示例：`genre=drama,sci-fi-fantasy`
- `country`（可选）
  - 国家/地区筛选，支持逗号分隔多值（OR 关系）
  - 示例：`country=united-states-of-america,japan`
- `year`（可选）
  - 年份精确匹配
  - 示例：`year=2026`
- `rating`（可选）
  - 最低分筛选
  - 支持：`gte_8_0` / `8+` / `8.0`
- `language`（可选）
  - 语言筛选，支持逗号分隔多值（OR 关系）
  - 示例：`language=english,japanese`

## 3. 请求示例

### 3.1 取电影分页

```bash
curl -G "https://api.nexamedia.app/api/content" \
  --data "type=1" \
  --data "page=1" \
  --data "size=20"
```

### 3.2 取电视剧分页

```bash
curl -G "https://api.nexamedia.app/api/content" \
  --data "type=2" \
  --data "page=1" \
  --data "size=20"
```

### 3.3 混合分页 + 关键词搜索

```bash
curl -G "https://api.nexamedia.app/api/content" \
  --data-urlencode "q=Game of Thrones" \
  --data "page=1" \
  --data "size=20"
```

### 3.4 TV 分页 + 五维筛选

```bash
curl -G "https://api.nexamedia.app/api/content" \
  --data "type=2" \
  --data-urlencode "genre=drama,sci-fi-fantasy" \
  --data-urlencode "country=united-states-of-america" \
  --data "year=2026" \
  --data "rating=gte_8_0" \
  --data-urlencode "language=english" \
  --data "page=1" \
  --data "size=30"
```

## 4. 返回结构

成功返回 `200 OK`：

```json
{
  "items": [
    {
      "id": "5",
      "movie_id": "1399",
      "type": 2,
      "title": "Game of Thrones",
      "img": "https://...",
      "cover_img": "https://...",
      "channels": {
        "UpCloud": "https://..."
      },
      "release_year": 2011,
      "updated_at": "2026-02-18T16:30:07.523Z"
    }
  ],
  "page": 1,
  "size": 20,
  "total": 1,
  "has_more": false
}
```

字段：
- `items`：内容列表
- `page`：当前页
- `size`：每页数量
- `total`：总条数
- `has_more`：是否还有下一页

## 5. 错误返回

- `type` 非法：
```json
{ "error": "invalid type, use 1(movie) or 2(tv)" }
```

- `page` 非法：
```json
{ "error": "invalid page" }
```

- `size` 非法：
```json
{ "error": "invalid size, range 1..500" }
```

- `year` 非法：
```json
{ "error": "invalid year" }
```

- `rating` 非法：
```json
{ "error": "invalid rating" }
```

## 6. 后端规则（当前实现）

- 自动过滤 `is_active = true`
- 排序规则：`updated_at DESC, id DESC`
- 返回前会移除 `raw` 字段

## 7. Android Retrofit 示例

```kotlin
interface ContentApi {
    @GET("api/content")
    suspend fun getContentPage(
        @Query("type") type: Int? = null, // 1 movie, 2 tv, null mixed
        @Query("page") page: Int = 1,
        @Query("size") size: Int = 30,
        @Query("q") q: String? = null,
        @Query("genre") genre: String? = null,       // e.g. "drama,sci-fi-fantasy"
        @Query("country") country: String? = null,   // e.g. "japan"
        @Query("year") year: Int? = null,            // e.g. 2026
        @Query("rating") rating: String? = null,     // e.g. "gte_8_0" / "8+"
        @Query("language") language: String? = null  // e.g. "english,japanese"
    ): ContentPageResponse
}

data class ContentPageResponse(
    val items: List<ContentItem> = emptyList(),
    val page: Int,
    val size: Int,
    val total: Int,
    val has_more: Boolean
)
```
