# 快速参考 - 常用命令

## 🚀 启动服务

```bash
# 开发模式（自动重启）
npm run dev

# 生产模式（正常运行）
npm start

# PM2 后台运行（推荐生产环境）
pm2 start src/index.js --name nexa-backend
```

---

## 📊 PM2 管理

```bash
pm2 status                    # 查看状态
pm2 logs nexa-backend         # 查看日志
pm2 restart nexa-backend      # 重启
pm2 stop nexa-backend         # 停止
pm2 delete nexa-backend       # 删除
```

---

## 🔄 更新部署

```bash
git pull                      # 拉取代码
npm install                   # 安装依赖
pm2 restart nexa-backend      # 重启服务
```

---

## 🔍 故障排查

```bash
# 查看端口占用
lsof -i :8080

# 杀掉进程
kill -9 <PID>

# 查看 PM2 错误日志
pm2 logs nexa-backend --err

# 健康检查
curl http://localhost:8080/health
```

---

## 🗄️ 数据库

```bash
npm run db:migrate            # 运行迁移
```

---

## 🛠️ 其他

```bash
pm2 save                      # 保存 PM2 配置
pm2 startup                   # 设置开机自启
pm2 monit                     # 监控资源使用
```
